# فصل هشتم: مدیریت نرم‌افزارها در لینوکس

## Linux Package Management

یکی از مهم‌ترین بخش‌های کار با سیستم‌عامل لینوکس، توانایی نصب، حذف، بروزرسانی و مدیریت نرم‌افزارها است.

در سیستم‌عامل‌های دیگر، کاربران معمولاً برای نصب برنامه‌ها به وب‌سایت‌های مختلف مراجعه می‌کنند و فایل نصب را دریافت می‌کنند.

اما در لینوکس، مدیریت نرم‌افزارها معمولاً از طریق یک سیستم استاندارد به نام:

Package Management

انجام می‌شود.

این سیستم به کاربران اجازه می‌دهد نرم‌افزارها را به شکل امن، سریع و سازمان‌یافته مدیریت کنند.

---

# Package چیست؟

در لینوکس، نرم‌افزارها معمولاً به صورت Package ارائه می‌شوند.

Package یک فایل شامل تمام اطلاعات مورد نیاز برای نصب یک نرم‌افزار است.

یک Package معمولاً شامل موارد زیر است:

- فایل‌های برنامه
- کتابخانه‌های مورد نیاز
- اطلاعات نسخه
- اطلاعات سازنده
- تنظیمات نصب

به زبان ساده:

Package یک بسته آماده برای نصب نرم‌افزار است.

---

# Package Manager چیست؟

Package Manager ابزاری است که وظیفه مدیریت Packageها را بر عهده دارد.

با استفاده از Package Manager می‌توان:

- نرم‌افزار نصب کرد.
- نرم‌افزار حذف کرد.
- نرم‌افزارها را بروزرسانی کرد.
- وابستگی‌های نرم‌افزارها را مدیریت کرد.
- اطلاعات Packageها را مشاهده کرد.

---

# Repository چیست؟

Repository یا مخزن نرم‌افزار، محلی است که Packageها در آن نگهداری می‌شوند.

توزیع‌های لینوکسی دارای Repositoryهای رسمی هستند که شامل هزاران نرم‌افزار بررسی‌شده هستند.

هنگامی که کاربر یک نرم‌افزار نصب می‌کند، Package Manager معمولاً ابتدا Repositoryها را بررسی می‌کند و سپس نرم‌افزار مورد نظر را دریافت می‌کند.

مزایای Repository:

- امنیت بیشتر
- بررسی شدن Packageها
- نصب ساده‌تر
- مدیریت بهتر بروزرسانی‌ها

---

# سیستم‌های مدیریت Package در لینوکس

توزیع‌های مختلف لینوکس از Package Managerهای متفاوتی استفاده می‌کنند.

مهم‌ترین آن‌ها:

## Debian Package System

در توزیع‌های Debian، Ubuntu و Linux Mint استفاده می‌شود.

فرمت Package:

    .deb

ابزارهای اصلی:

    apt
    dpkg

---

## Red Hat Package System

در توزیع‌های Red Hat، Fedora و CentOS استفاده می‌شود.

فرمت Package:

    .rpm

ابزارهای اصلی:

    dnf
    yum
    rpm

---

# APT چیست؟

APT مخفف:

Advanced Package Tool

است.

APT یکی از مهم‌ترین ابزارهای مدیریت نرم‌افزار در خانواده Debian است.

توزیع‌هایی مانند:

- Ubuntu
- Debian
- Linux Mint

از APT استفاده می‌کنند.

---

# بروزرسانی اطلاعات Packageها

قبل از نصب یا بروزرسانی نرم‌افزارها بهتر است اطلاعات Repositoryها را بروزرسانی کنیم.

دستور:

    sudo apt update

این دستور لیست Packageهای موجود را دریافت و بروزرسانی می‌کند.

نکته:

این دستور خود نرم‌افزارها را بروزرسانی نمی‌کند؛ فقط اطلاعات موجود بودن نسخه‌های جدید را بررسی می‌کند.

---

# بروزرسانی نرم‌افزارها

برای بروزرسانی Packageهای نصب شده:

    sudo apt upgrade

استفاده می‌شود.

این دستور نسخه‌های جدید نرم‌افزارهای نصب شده را دریافت و نصب می‌کند.

---

# نصب نرم‌افزار

برای نصب یک Package:

    sudo apt install package-name

مثال:

    sudo apt install vim

در این مثال، ویرایشگر Vim نصب می‌شود.

---

# حذف نرم‌افزار

برای حذف یک Package:

    sudo apt remove package-name

مثال:

    sudo apt remove vim

این دستور برنامه را حذف می‌کند.

---

# حذف کامل نرم‌افزار

گاهی اوقات علاوه بر فایل برنامه، تنظیمات آن نیز باید حذف شود.

برای این کار:

    sudo apt purge package-name

استفاده می‌شود.

تفاوت:

remove:
فقط فایل‌های برنامه را حذف می‌کند.

purge:
برنامه و فایل‌های تنظیمات آن را حذف می‌کند.

---

# جستجو در Packageها

برای پیدا کردن یک نرم‌افزار:

    apt search package-name

مثال:

    apt search browser

---

# مشاهده اطلاعات یک Package

برای مشاهده اطلاعات یک Package:

    apt show package-name

مثال:

    apt show nginx

---

# dpkg چیست؟

dpkg ابزار سطح پایین مدیریت Packageهای Debian است.

APT معمولاً برای مدیریت Packageها از dpkg استفاده می‌کند.

dpkg مستقیماً با فایل‌های:

    .deb

کار می‌کند.

---

# نصب Package با dpkg

اگر یک فایل deb دانلود کرده باشیم:

    sudo dpkg -i package.deb

آن را نصب می‌کند.

---

# مشکل وابستگی‌ها

گاهی هنگام نصب با dpkg ممکن است خطای وابستگی دریافت کنیم.

برای رفع مشکلات:

    sudo apt install -f

APT وابستگی‌های مورد نیاز را بررسی و اصلاح می‌کند.

---

# Snap چیست؟

Snap یک سیستم مدیریت Package دیگر است که توسط Canonical توسعه داده شده است.

Snap برنامه‌ها را همراه با وابستگی‌های مورد نیازشان ارائه می‌دهد.

مزیت:

- نصب ساده
- اجرای مستقل
- نسخه‌های جدیدتر نرم‌افزارها

دستور نصب:

    sudo snap install package-name

مثال:

    sudo snap install code

---

# Flatpak چیست؟

Flatpak یک سیستم توزیع نرم‌افزار مستقل از توزیع لینوکس است.

هدف Flatpak این است که برنامه‌ها بدون وابستگی به نوع سیستم‌عامل اجرا شوند.

مزایا:

- امنیت بیشتر
- سازگاری بالا
- اجرای برنامه‌ها در محیط جدا

---

# مدیریت سرویس‌ها

برخی نرم‌افزارها پس از نصب به صورت Service اجرا می‌شوند.

برای مثال:

- Web Server
- Database Server
- SSH Server

مدیریت این سرویس‌ها معمولاً با systemd انجام می‌شود.

---

# مشاهده وضعیت یک سرویس

دستور:

    systemctl status service-name

مثال:

    systemctl status ssh

---

# شروع یک سرویس

    sudo systemctl start service-name

مثال:

    sudo systemctl start ssh

---

# توقف یک سرویس

    sudo systemctl stop service-name

---

# فعال کردن اجرای خودکار سرویس

برای اجرای سرویس هنگام روشن شدن سیستم:

    sudo systemctl enable service-name

---

# غیرفعال کردن اجرای خودکار

    sudo systemctl disable service-name

---

# مدیریت نرم‌افزار از طریق سورس

در لینوکس همیشه نرم‌افزارها از Repository نصب نمی‌شوند.

گاهی کاربران برنامه را از Source Code دریافت کرده و خودشان کامپایل می‌کنند.

مراحل کلی:

دریافت کد:

    git clone repository-url

ورود به پوشه:

    cd project

ساخت برنامه:

    make

نصب:

    sudo make install

---

# چرا مدیریت Package مهم است؟

شناخت Package Manager یکی از مهارت‌های پایه لینوکس است.

بدون آن، مدیریت سیستم بسیار سخت خواهد شد.

یک کاربر حرفه‌ای لینوکس باید بتواند:

- نرم‌افزار نصب کند.
- مشکلات وابستگی را حل کند.
- Packageها را بروزرسانی کند.
- سرویس‌ها را مدیریت کند.
- منابع نرم‌افزاری سیستم را کنترل کند.

---

# تمرین‌های فصل هشتم

## تمرین اول

لیست Packageهای سیستم را بروزرسانی کنید:

    sudo apt update

---

## تمرین دوم

یک نرم‌افزار نصب کنید:

    sudo apt install htop

---

## تمرین سوم

اطلاعات یک Package را مشاهده کنید:

    apt show htop

---

## تمرین چهارم

یک Package را حذف کنید:

    sudo apt remove htop

---

## تمرین پنجم

وضعیت سرویس SSH را بررسی کنید:

    systemctl status ssh

---

# جمع‌بندی فصل هشتم

در این فصل یاد گرفتیم:

- Package چیست.
- Package Manager چگونه کار می‌کند.
- Repository چه کاربردی دارد.
- چگونه با APT نرم‌افزار نصب کنیم.
- چگونه Packageها را حذف و بروزرسانی کنیم.
- تفاوت apt و dpkg چیست.
- Snap و Flatpak چگونه کار می‌کنند.
- چگونه سرویس‌های لینوکس را مدیریت کنیم.

مدیریت نرم‌افزارها یکی از پایه‌های اصلی کار با لینوکس است و بدون یادگیری آن، کنترل حرفه‌ای یک سیستم لینوکسی امکان‌پذیر نیست
